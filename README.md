## ✨ Features

| Feature | Description |
|---------|-------------|
| 🍛 **22+ Indian Recipes** | North Indian, South Indian, Snacks & Desserts |
| 🔍 **Search Functionality** | Real-time search by recipe name |
| 🏷️ **Category Filters** | Filter by cuisine type (North, South, Snacks, Desserts) |
| ⭐ **Favorites System** | Save favorite recipes using browser's LocalStorage |
| 📱 **Fully Responsive** | Works on phone, tablet, laptop, monitor & TV |
| 🖼️ **Recipe Modal** | Click any recipe to see detailed ingredients & steps |
| 🎨 **Beautiful UI** | Warm Indian color theme with smooth animations |
| 💾 **No Backend Required** | Pure HTML/CSS/JS - runs entirely in browser |
